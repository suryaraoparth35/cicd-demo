# CI/CD Demo Project

A simple Node.js application demonstrating a complete **CI/CD and DevOps workflow** using GitHub, Jenkins, Docker, and Kubernetes.

## 🚀 Project Overview

This project is created to understand how an application can be developed, tested, containerized, and deployed using modern DevOps tools.

The workflow includes:

- Source code management with Git and GitHub
- Automated testing with Node.js
- Continuous Integration using Jenkins
- Containerization using Docker
- Kubernetes deployment and service configuration

## 🛠️ Technologies Used

- **Node.js** – Application runtime
- **Express.js** – Backend framework
- **Jest** – Testing
- **Git & GitHub** – Version control
- **Jenkins** – CI/CD automation
- **Docker** – Containerization
- **Kubernetes** – Container orchestration
